Technical Writing Portfolio - Lars Nilsson

A collection of S1000D and ILS learning projects, structured documentation case studies, and DITA/XML manuals.

Structured documentation, ILS thinking, and practical learning

I’ve spent years in IT support, troubleshooting systems, working with identity management, and writing internal documentation in Confluence. That background shaped how I approach technical writing: documentation should be clear, structured, maintainable, reusable, and useful in real workflows. Some projects here are production-style case studies; others are tools I built to explore and understand complex documentation standards in practice.

Selected Projects

S1000D Mini-CSDB — Interactive Emulator

An interactive browser-based CSDB emulator built around the S1000D Issue 6 Bike sample dataset. Explore data modules, publication modules and ICN objects, follow references and where-used relationships, inspect issue history and source XML, and simulate a controlled author > review > approval workflow with a separate authoring-editor view.

HX-20 Legacy Maintenance Manual to S1000D

A realistic S1000D migration case study showing how a fictional helicopter maintenance procedure can be audited, split into data modules, assigned DMCs, structured with applicability for MK1/MK2 variants, and assembled through a publication module. Includes source DOCX, PDF preview, mini DMRL, simplified S1000D-style XML modules, operational test module, and ICN-style technical illustration.

S1000D DMC DMRL Applicability XML Maintenance Documentation ILS
